🔐 Pag-login sa Portal
Ganito ang hitsura ng login screen ng DBAMINHS School Portal. Gamitin ang iyong Employee ID at password para makapasok bilang Teacher.

📋 MGA HAKBANG

1
Buksan ang portal URL sa Chrome o Safari — huwag gumamit ng Facebook Messenger browser
2
I-click ang "Teacher" tab sa itaas ng login form
3
I-type ang iyong Employee ID at Password
4
I-click ang "Log In →" button
💡 Opsyonal: Kapag na-setup na ang Fingerprint Login, pwede kang gumamit ng "🔒 Login with Fingerprint" button para mas mabilis na pag-login sa susunod.

📊 Grade Input — Pag-upload ng Grades
Ito ang pinakamahalagang feature. Sundin ang mga hakbang para ma-upload ang grades ng iyong section bawat term.

📋 MGA HAKBANG SA PAG-UPLOAD NG GRADES

1
Pumunta sa Grade Input tab
2
Piliin ang iyong Class / Section at ang tamang Term (Term 1, 2, o 3)
3
I-click ang "📥 Download CSV Template" — mag-do-download ng file na may pre-filled na pangalan ng students
4
Buksan sa Excel, i-encode ang grades (60–100), at i-save bilang CSV format (hindi .xlsx)
5
I-click ang "📤 Upload CSV File" at piliin ang na-save na file
6
Tingnan ang grade table sa ibaba para i-verify na tama ang lahat
⚠️ HUWAG i-delete ang "--- MALE ---" at "--- FEMALE ---" rows sa CSV — awtomatiko silang nalilipat ng sistema.

📋 Attendance — Pag-upload ng Presensya
Katulad ng grades, maaari ka ring mag-upload ng attendance records ng iyong klase gamit ang CSV template.

📋 MGA HAKBANG SA PAG-UPLOAD NG ATTENDANCE

1
Pumunta sa Attendance tab
2

3

5

💡 Ang mga student ay nakaayos na Male (A-Z) tapos Female (A-Z) sa template — katulad ng grade template.

🔑 Forgot Password
Nakalimutan ang password? Maaari kang mag-submit ng reset request sa pamamagitan ng portal — ang Admin ang mag-a-approve ng pagbabago.

📋 MGA HAKBANG SA PASSWORD RESET

1
Sa Login screen, i-click ang "Forgot Password?" link
2
I-type ang iyong Employee ID o Email
3
I-type ang iyong bagong password (minimum 8 characters) at kumpirmahin
4
I-click ang "Submit Request" — ipapadala ang request sa Admin para sa pag-review
5
Hintayin ang approval ng Admin — kapag na-approve, maaari kang mag-login gamit ang bagong password
⚠️ Maaaring kausapin ka ng Admin nang personal para i-verify ang iyong pagkakakilanlan bago i-approve ang request — ito ay para sa seguridad ng iyong account.
pcselgajr.github.io/307714dbaminhs/ — Forgot Password

🔑 Forgot Password

Walang automatic na email reset sa portal na ito. Mag-submit ng iyong ID at bagong password — ang Admin ang mag-a-approve ng pagbabago pagkatapos i-verify ang iyong pagkakakilanlan.

✅ Na-submit ang iyong request! Hintayin ang Admin na mag-approve. Maaari kang mag-login gamit ang bagong password kapag na-approve na.

🎓 Student Login at Dashboard
Ganito ang paraan para mag-login ang isang student at makita ang kanyang grades at attendance sa portal.

📋 PAANO MAG-LOGIN BILANG STUDENT

Maaari ring mag-login ang magulang para makita ang grades at attendance ng kanilang anak — kahit wala silang hawak na report card.
